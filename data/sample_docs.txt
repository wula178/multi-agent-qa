检索增强生成（Retrieval-Augmented Generation，简称 RAG）是一种把外部知识检索与大语言模型生成结合起来的技术。它的核心流程包括：文档解析、文本切分、向量化、检索召回、重排和生成。RAG 能显著降低大模型的幻觉，因为它让模型基于检索到的真实资料回答，而不是仅靠参数记忆。

混合检索指的是同时使用关键词检索和向量检索两种方式。关键词检索（如 BM25）擅长精确匹配专有名词、编号和代码片段，向量检索擅长捕捉语义相似。两者融合的常用方法是倒数排名融合（RRF），它对两种检索结果的排名取倒数再相加，避免不同分数量纲带来的权重调参问题。

Embedding 模型把文本映射成向量。bge-m3 是一种支持稠密、稀疏和多向量三种检索模式的中文 embedding 模型，输入长度长，适合私有化部署。检索时用 query 和文档向量的余弦相似度打分。

重排（Rerank）是对初步召回结果做精排。召回阶段常用双编码器（bi-encoder），速度快但精度有限；重排阶段常用交叉编码器（cross-encoder），把问题和候选段落拼在一起做深度交互，精度更高。bge-reranker 是常见的中文重排模型。

多 Agent 系统把任务拆给多个角色协作完成，常见分工包括：规划者、执行者、检索者、校验者。LangGraph 是一种用图结构编排 Agent 的框架，通过共享状态和条件边控制节点之间的流转，支持循环和反思重试。校验者 Agent 可以检查生成结果是否忠实于上下文，不通过时把反馈传回生成环节重试，从而降低幻觉。

评测 RAG 系统常用 RAGAS 框架，核心指标包括忠实度（faithfulness）、答案相关性（answer relevancy）、上下文精确度（context precision）和上下文召回率（context recall）。忠实度衡量答案是否被检索到的上下文支撑。
